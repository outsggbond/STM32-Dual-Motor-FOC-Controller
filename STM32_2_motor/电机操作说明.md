# 双电机操作说明

**这份是"敲什么命令、电机怎么转"。** 硬件接线、故障位含义、测试数据这些在另一份
`使用说明.md` 里，本文只在必要处点一下。

---

## 0. 一分钟上手

连上 COM4（115200 8N1，**每条命令结尾必须是回车换行 `\r\n`**），然后：

```
M1 CLR            ← 清故障（第一次上手先做，图个干净）
M1 SPD 5          ← 电机 1 以 5 rad/s 转起来
M2 SPD 5          ← 电机 2 也转
STOPALL           ← 两个都停
```

就这四条。下面都是细节。

> **先看 §9「最容易犯的五个错」**，那五条能挡掉九成的"怎么不转 / 怎么乱转"。

---

## 1. 上电后先确认两件事

**每次上电，两个电机都会自己动一下** —— 这是开机换相校准，在收到任何命令之前发生，正常，别慌。

等它自己转完，敲：

```
STATUS
```

看每个电机的 **`ERR`**：

- `ERR=0` → 正常，往下走
- `ERR≠0` → 先 `M1 CLR` / `M2 CLR` 清掉再试

（`VTRV` 那个数是**开机自检的行程**，不是电压，看一眼非零就行，之后不会再变。）

---

## 2. 让它转 —— 速度模式

```
M1 SPD 5
```

`SPD` 后面是**角速度，单位 rad/s**（不是 RPM，不是度）。

| 想要 | 敲 |
|---|---|
| 慢慢转 | `M1 SPD 1` |
| 中速 | `M1 SPD 5` |
| 快 | `M1 SPD 20` |
| **反着转** | 加负号：`M1 SPD -5` |
| 最快 | 到 **58 rad/s** 左右封顶，再大也上不去了（被电压限住） |

**换速度直接再发一条就行**，不用先停：

```
M1 SPD 5
M1 SPD 15        ← 直接升上去，无縫
```

**★ 别低于 0.5 rad/s。** 再慢就进摩擦死区，电机会一走一停地"蹭"（stick-slip），
那是低速摩擦的正常现象，不是故障，但也没法当稳定转速用。

---

## 3. 停下

**有两种停，用途不一样：**

| 命令 | 效果 | 什么时候用 |
|---|---|---|
| `M1 SPD 0` | **通电刹住**，有保持力 | 想让它**停在那儿别动** |
| `M1 STOP` | **断电自由滑行**，无保持力 | 想让它**松开、用手能拨动** |
| `STOPALL` | 两个一起停（= 两个 `STOP`） | 紧急停 |

**★ 这是最容易搞错的一条：`STOP` 停了之后，转子还在滑，用手一拨就转。**
如果你要的是"停住"，用 `SPD 0`。

---

## 4. 转到指定角度 —— 位置模式

**两步：先定零点，再发角度。**

```
M1 SPD 0                  ← 先停住（重要，见下面★）
（等 1 秒）
M1 STATUS                 ← 记下 ANGLE
M1 STATUS                 ← 再读一次，两次数字一样 = 真的静止了
M1 ZERO                   ← 把"现在这里"定为 0 度
M1 POS 90                 ← 转到 90 度
```

之后 `POS` 的值都是**相对这个零点**的角度（度）：

```
M1 POS 0          ← 转回零点
M1 POS -45        ← 往反方向 45 度
M1 POS 180
```

### ★ 发 `ZERO` 之前必须确认转子真的停了

`ZERO` 不管转子在不在动。**在还在滑的时候发 `ZERO`，会把错误的原点记下来**，
之后所有 `POS` 全错，表现是"莫名其妙多转好几圈"。

**判断方法：连读两次 `STATUS`，`ANGLE` 完全一样，才发 `ZERO`。**

### 到位了没有？

**没有"到位"这个提示**（`STATE` 变回 `READY` 也不代表到了）。自己看数：

```
M1 STATUS
```

`ANGLE` 追上了 `TARGET` 就是到了。**90 度大约要 1~1.5 秒。**

**★ 会冲过头。** 这个位置环没有阻尼，会超调 **2~4.5°** 再退回来，
后面还有 **1~3.5 秒**的小尾巴在慢慢爬到位。所以别在 1 秒时就说"它没到" —— 再等等。

**停住之后不会飘**（实测保持漂移 0.000°），但**前提是别发 `STOP`** ——
`STOP` 一断，保持力就没了，重力会把镜子拽走。

---

## 5. 两个电机一起

两个电机**完全独立**，随便组合：

```
M1 SPD 8
M2 SPD 8              ← 两个同速转（实测各稳在 8.0 rad/s，互不影响）
```

```
M1 POS 90
M2 POS -30            ← 一个定位、一个定位
```

```
M1 POS 45
M2 SPD 10             ← 一个定位，一个同时调速，都行
```

## 6. 常用需求速查

| 我要… | 敲 |
|---|---|
| 转起来 | `M1 SPD 5` |
| 慢点 / 快点 | `M1 SPD 2` / `M1 SPD 20` |
| 反向 | `M1 SPD -5` |
| 停住（有保持力） | `M1 SPD 0` |
| 松开（可手拨） | `M1 STOP` |
| 两个都停 | `STOPALL` |
| 转到 90 度 | `M1 ZERO` → `M1 POS 90`（**先等静止**） |
| 回零点 | `M1 POS 0` |
| 看当前角度 / 速度 | `M1 STATUS` |
| 清故障 | `M1 CLR` |
| 两轴同速对转 | `M1 SPD 8` + `M2 SPD -8` |

---

## 7. 出故障了

`STATUS` 里 `ERR` 不是 0 就是有故障。**最常见的是 `ERR=32`（堵转保护）** ——
电机被通着电却转不动（顶到限位、被别住、或者开环 `VOL` 顶着一个静止的转子）。

```
M1 CLR            ← 清掉，重新发 SPD
```

**清不掉 / 清完马上又跳** → 先排除机械上真的别住了，再看下面：

| `ERR` | 含义 | 怎么办 |
|---|---|---|
| `32` | 堵转 | `CLR`；检查是不是真卡住了 |
| `64` | 过热 | 等冷却，然后 `CLR`（正常用不会触发） |
| `2` | **I²C 编码器故障** | **`CLR` 可能没用，多半要断电重上** |
| 其他 | 编码器/校准/超速 | `CLR`，不行就断电重上 |

**★ 记一个反直觉的现象：故障好了之后 `ERR` 还会一直挂着。**
电机已经正常转了，`ERR=32` 还显示在那儿 —— **这是正常的，`CLR` 一下就好**，别以为又坏了。

**现场演示的建议：手边留一个电源开关。** `ERR=2` 有时只能靠断电解决。

## 8. 想让慢速更顺、定位更准（进阶）

| 命令 | 作用 |
|---|---|
| `M1 FF 1.5` | **静摩擦前馈**。低速"蹭"得厉害时加一点，会顺很多（默认 0=关） |
| `M1 TRAJ 20 60` | 制动力曲线（`vmax` `amax`）。**能把定位超调砍掉约 30%** |
| `M1 LIMIT 4` | 限制速度环输出电压上限（默认 6.6 V） |

定位那条 1~3.5 秒的尾巴，主要就是 `FF=0` 造成的 —— 想让它收得干净，试试开前馈。

---

## 9. ★ 最容易犯的五个错

1. **命令结尾没发 `\r\n`** → 固件完全当没收到，看起来像"死机"。
2. **`STOP` 当刹车用** → `STOP` 是断电滑行，不是停住。要停住用 `SPD 0`。
3. **没等静止就发 `ZERO`** → 原点锁错，之后所有角度全偏。
4. **看 `STATE=READY` 就以为到位了** → 它只表示"没在闭环"，不代表角度到了。看 `ANGLE` vs `TARGET`。
5. **1 秒时判断"没到位"** → 超调 + 长尾巴，得等 3 秒左右才算真停稳。

## 10. 卡片

```
连：COM4  115200  8N1  结尾 \r\n

转：M1 SPD 5          停住：M1 SPD 0        松开：M1 STOP
定位：M1 ZERO → M1 POS 90      （发 ZERO 前等 ANGLE 两次读数一致）
看：M1 STATUS         清故障：M1 CLR        急停：STOPALL

量程：0.5 ~ 58 rad/s      90° 约 1~1.5 s（会超调 2~4.5°）
```
